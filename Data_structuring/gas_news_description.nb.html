Il faut se fixer un seuil d’identification des chocs potentiellement variable avec le temps. Une normalisation par rapport à la quantité de news disponibles. Il peut être différent pour les supply and demand, puisqu’il semble qu’il y ait plus de nouvelles de supply que de demand.

Definir un seuil flottant par supérieur à 3 fois la moyenne du mois On double checke en regardant le nombre de jours d’annonce que cela permet de sélectionner.


shock_data <- event_complete_data %>%
  arrange(datetime) %>%  # Replace 'date_column' with your actual date column name
  mutate(moving_avg_news = rollapply(news_per_day, width = 30, FUN = mean, fill = NA, align = "right"),
        moving_std_news = rollapply(news_per_day, width = 30, FUN = sd, fill = NA, align = "right"),
       binary_shock= (news_per_day >  moving_avg_news + 4*moving_std_news),
       intensity_shock = ifelse(binary_shock, news_per_day/moving_avg_news, 0)
       )

instrument_days <- shock_data %>% 
  filter(binary_shock ==TRUE) %>% 
  filter(event_type== 'demand' | news_per_day > 2)


instrument_results <- full_dates %>%
